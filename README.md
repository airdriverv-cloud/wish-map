# Карта желаний — сайт

Живая карта желаний Виктора: отмечать сбывшееся, добавлять новые цели, делиться прогрессом и смотреть мультяшный фильм.

**Живая версия:** https://airdriverv-cloud.github.io/wish-map/
**Репозиторий:** https://github.com/airdriverv-cloud/wish-map

## Возможности

- 10 стартовых желаний с прогрессом и фильтрами.
- Отметка «сбылось» с анимацией и сохранением в `localStorage`.
- Добавление, редактирование и удаление желаний.
- Поделиться картой: состояние кодируется в ссылке, друг может посмотреть и «забрать себе».
- Замена изображения у карточки: кнопка «Заменить» → стиль **Фото / Мульт / Кино** → описание → кадр подбирается или генерируется **без регистрации**.
- Мультяшный фильм `assets/video/wish-map.mp4` со звуком.
- Маршрут года: 8 остановок, синхронизированных с отметками желаний.
- Блок «Как это работает»: написать → собрать → жить.

## Локальный запуск

```powershell
cd wish-map
python -m http.server 8080
```

Открыть http://127.0.0.1:8080/

## Структура

- `index.html` — разметка
- `style.css` — базовые стили и адаптив
- `app.css` — модалки, карточки, видеокарта (вынесено отдельно, чтобы стили не обрезались в кэше)
- `script.js` — желания, localStorage, шеринг, замена кадров, маршрут, видеокарта
- `assets/fonts/` — Cormorant Garamond и Manrope (OFL)
- `assets/img/` — карточки желаний, сцены и постеры видео
- `assets/video/wish-map.mp4` — мультяшный фильм, 1920×1080

## Публикация

GitHub Pages: ветка `main`, корень репозитория. Файл `.nojekyll` уже добавлен.

Сайт закрыт от индексации через `<meta name="robots">` и `robots.txt`, но доступен по прямой ссылке.

## Замена кадров

Кнопка «Заменить» открывает окно без GitHub и регистрации.

**Способ:**
- «Найти» — подбор фото через Wikimedia Commons.
- «Ноут» — генерация в локальном ComfyUI через мост `http://127.0.0.1:8190`.
- «FAL» — генерация через FAL по PIN **6620** через мост `http://127.0.0.1:8189`.

**Вид:** Мульт, Реалити, Аниме, Акварель, Неон, 3D.

Локальные мосты запускаются на ноутбуке:

```powershell
python wishmap-viktor/comfy_bridge.py
python wishmap-viktor/fal_bridge.py
```

Если мост не запущен, способ откатывается на резервную генерацию или подбор фото. Результат сохраняется в `localStorage` вместе с картой.
