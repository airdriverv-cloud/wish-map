# Карта желаний — сайт

Живая карта желаний Виктора: отмечать сбывшееся, добавлять новые цели, делиться прогрессом и смотреть мультяшный фильм.

**Живая версия:** https://airdriverv-cloud.github.io/wish-map/
**Репозиторий:** https://github.com/airdriverv-cloud/wish-map

## Возможности

- 10 стартовых желаний с прогрессом и фильтрами.
- Отметка «сбылось» с анимацией и сохранением в `localStorage`.
- Добавление, редактирование и удаление желаний.
- Поделиться картой: состояние кодируется в ссылке, друг может посмотреть и «забрать себе».
- Замена изображения у карточки: кнопка «Заменить» → режимы **Найти / Ноут / FAL** → описание → заявка в GitHub Issues с меткой `image-request` (или копирование текста в чат).
- Мультяшный фильм `assets/video/wish-map.mp4` со звуком.
- Карта в большом формате и паспорт желаний в PDF.

## Локальный запуск

```powershell
cd wish-map
python -m http.server 8080
```

Открыть http://127.0.0.1:8080/

## Структура

- `index.html` — разметка
- `style.css` — стили, адаптив
- `script.js` — желания, localStorage, шеринг, заявки на изображения, табы, лайтбокс
- `assets/fonts/` — Cormorant Garamond и Manrope (OFL)
- `assets/img/` — веб-версии карты, карточек и постер видео
- `assets/video/wish-map.mp4` — мультяшный фильм, 1920×1080
- `assets/karta-zhelaniy-viktor.pdf` — двухстраничный PDF A4

## Публикация

GitHub Pages: ветка `main`, корень репозитория. Файл `.nojekyll` уже добавлен.

Сайт закрыт от индексации через `<meta name="robots">` и `robots.txt`, но доступен по прямой ссылке.

## Заявки на изображения

Заявки создаются как GitHub Issues с меткой `image-request` и назначаются на `airdriverv-cloud`. Режимы: «Найти» — подобрать готовое фото, «Ноут» — сгенерировать локально, «FAL» — сгенерировать через fal.ai. Пока это ручной процесс: заявка фиксирует желание, режим и описание.
