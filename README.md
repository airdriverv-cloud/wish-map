# Карта желаний — сайт

Живая карта желаний Виктора: отмечать сбывшееся, добавлять новые цели, делиться прогрессом и смотреть мультяшный фильм.

**Живая версия:** https://airdriverv-cloud.github.io/wish-map/
**Репозиторий:** https://github.com/airdriverv-cloud/wish-map

## Возможности

- 10 стартовых желаний с прогрессом и фильтрами.
- Отметка «сбылось» с анимацией и сохранением в `localStorage`.
- Добавление, редактирование и удаление желаний.
- Поделиться картой: состояние кодируется в ссылке, друг может посмотреть и «забрать себе».
- Замена изображения у карточки: кнопка «Заменить» → стиль **Фото / Мульт / Кино** → описание → кадр подбирается или генерируется **без регистрации**.
- Мультяшный фильм `assets/video/wish-map.mp4` со звуком.
- Маршрут года: 8 остановок, синхронизированных с отметками желаний.
- Коллаж: 3 композиции (мозаика, сетка, полароиды) применяются к карточкам; выбор и кнопка «Сохранить вид» сохраняются в браузере.
- Вид своей карты: 2 столбика, 4 столбика или «Как сейчас»; выбор сохраняется в браузере.
- Отдельная страница `examples.html`: 50 готовых желаний по типам, просмотр в 2, 4 или 5 столбцов, добавление в карту одной кнопкой.
- Карта делится на типы: путешествия, тело, дело, любовь, творчество.
- Блок «Как это работает»: написать → собрать → жить.

## Локальный запуск

```powershell
cd wish-map
python -m http.server 8080
```

Открыть http://127.0.0.1:8080/

## Структура

- `index.html` — разметка
- `style.css` — базовые стили и адаптив
- `app.css` — модалки, карточки, видеокарта (вынесено отдельно, чтобы стили не обрезались в кэше)
- `script.js` — желания, localStorage, шеринг, замена кадров, маршрут, видеокарта
- `assets/fonts/` — Cormorant Garamond и Manrope (OFL)
- `assets/img/` — карточки желаний, сцены и постеры видео
- `assets/video/wish-map.mp4` — мультяшный фильм, 1920×1080

## Замена кадров

Кнопка «Заменить» открывает окно без GitHub и регистрации.

**Способ:**
- «Найти» — подбор фото через Wikimedia Commons.
- «Ноут» — генерация в локальном ComfyUI через мост `http://127.0.0.1:8190`; если локальный мост недоступен, сайт пробует удалённый `https://vik-laptop.tailebabca.ts.net:8443` (Tailscale Funnel).
- «FAL» — генерация через FAL по PIN **6620** (нужен для каждой FAL-генерации) через мост `http://127.0.0.1:8189`. PIN — это UI-защита от случайного запуска, не секрет.

**Вид:** Мульт, Реалити, Аниме, Акварель, Неон, 3D.

**Тип:** картинка или видео. Видео генерируется через FAL LTX 2.3 (6/8/10 секунд, 9:16). Ориентир: кадр ≈ $0.0015, видео 6 с ≈ $0.48. В блоке FAL показывается остаток и примерное количество доступных кадров/видео; для остатка ключу FAL нужно право `billing:usage:read`.

Описание кадра сохраняется отдельно для каждого желания и переживает перезагрузку страницы.

### Галерея кадров

- Можно генерировать от 1 до 10 вариантов за раз.
- Все варианты сохраняются в карточке желания в `gallery`.
- В окне «Заменить кадр» можно поставить любой кадр или удалить его.
- Сгенерированные data-URI сжимаются до 640×800 JPEG, чтобы не переполнить `localStorage`.
- На карточке показывается «Кадры · N», если вариантов больше одного.

Локальные мосты запускаются на ноутбуке:

```powershell
python wishmap-viktor/comfy_bridge.py
python wishmap-viktor/fal_bridge.py
```

### Видео на ноутбуке

Режим «Ноут» умеет генерировать короткое видео локально через Wan 2.1 T2V 1.3B в ComfyUI:

- 480×832, 9:16, около 2 секунд, без звука;
- занимает примерно 3–4 минуты на RTX 3060 Laptop;
- файл лежит в `wishmap-viktor/video_out/` и отдаётся мостом по `/video/<id>.mp4`.

ComfyUI должен видеть Wan-модели из портативной сборки. Для этого в `C:\AI\ComfyUI\extra_model_paths.yaml` добавлен путь к `ai/ComfyUI_windows_portable/ComfyUI`. После изменения конфига ComfyUI перезапускается.

### Ноут из интернета

Мост ComfyUI уже защищён PIN-кодом `6620` и лимитом запросов. Чтобы открыть его наружу, один раз включите Tailscale Funnel для узла и запустите:

```powershell
tailscale funnel --bg --https 8443 8190
```

Сайт сначала пробует локальный `127.0.0.1:8190`, затем удалённый `https://vik-laptop.tailebabca.ts.net:8443`. PIN проверяется на мосте; это защита от случайного доступа, а не полноценная авторизация. Для публичного сервиса нужен Cloudflare Access/аккаунты.

Если мост не запущен, способ откатывается на резервную генерацию или подбор фото. Результат сохраняется в `localStorage` вместе с картой.
